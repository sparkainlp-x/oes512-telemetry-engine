# OES-512 Telemetry Engine

[![CI](https://github.com/sparkainlp-x/oes512-telemetry-engine/actions/workflows/ci.yml/badge.svg)](https://github.com/sparkainlp-x/oes512-telemetry-engine/actions/workflows/ci.yml)
[![License: AGPL-3.0-only](https://img.shields.io/badge/License-AGPL--3.0--only-blue.svg)](LICENSE)

A small asynchronous Python prototype that frames, filters and summarizes **synthetic** 512-channel telemetry.

> **Scope:** all input is generated by the built-in producer. This is a software prototype. It is not acquisition hardware, it has no connection to real sensors, and no latency or throughput has been measured. The alert thresholds are uncalibrated defaults.

## What it does

1. **Framing.** `OES512TelemetryProducer` packs each sample as a binary frame: a 5-byte magic header, sequence ID, timestamp, 512 float32 values and a 32-bit additive checksum. `OES512TelemetryParser` rejects incomplete frames, wrong headers and checksum mismatches.
2. **Filtering.** Each channel passes through a stateful 50 Hz notch filter (Q = 30) and then a 4th-order Butterworth 0.5–45 Hz bandpass, at a nominal 250 Hz.
3. **Summary statistics** over a rolling window (default 512 samples):
   - **coherence:** the mean absolute Pearson correlation between every 16th channel (32 of 512). Constant channels are left out.
   - **instability:** the standard deviation of the per-channel variances.
   - **drift:** the Euclidean distance between the current per-channel mean and the first full window's mean.
4. **Alerts.** The default thresholds are coherence below 0.20 or above 0.85, instability above 15 and drift above 25. Alerts are appended to a local log file. Alert POSTs to a webhook are **off by default**; they are sent only if you pass `--webhook-url`.

The synthetic signal is a sine wave at 8.0–9.4 Hz on each channel plus a common 50 Hz tone. From frame 700 onward, every 32nd channel also gets a +60 step offset, a synthetic disturbance for exercising the alert path. Signal time is `seq_id / 250`, so runs are reproducible.

## Quickstart

Python 3.10+.

```bash
pip install -r requirements.txt
python main.py --fast              # 1,000 synthetic frames, no sleeping
python main.py --packets 2000      # paced at the nominal 250 Hz
python main.py --fast --webhook-url http://localhost:8080/oes-webhook   # optional
```

## Tests

```bash
pip install -r requirements.txt -r requirements-dev.txt
pytest -q
```

The tests cover the frame round trip, rejection of bad frames, deterministic payloads, 50 Hz attenuation and 10 Hz passband behaviour, the metric definitions and NaN-safety, the alert thresholds, the webhook being off by default, and an end-to-end run in which alerts begin only after the synthetic step. All test inputs are SYNTHETIC.
